The rules for moving a repo script's logic from PowerShell to Python are:

- **Thin wrapper**: PowerShell scripts invoke Python modules via `Invoke-DatrixPythonScript` (datrix/scripts/quick-reference.md:27).
- **Lib module**: Python logic resides in `scripts/<folder>/lib/` or shared `scripts/common/lib/datrix_scripts/` (datrix/scripts/quick-reference.md:149).
- **Self-test**: PowerShell gate scripts support `-SelfTest` for non-vacuity proof and seam checks (datrix/scripts/test/quick-reference.md:750).
- **R1-R5**: Python modules must match PowerShell behavior for log naming/claiming using `O_CREAT|O_EXCL` (datrix/scripts/test/quick-reference.md:742), support bash invocation with forward slashes and quotes (datrix/scripts/quick-reference.md:5-25), avoid path escape issues (datrix/scripts/quick-reference.md:30-32), and maintain security posture without network calls or subprocesses (datrix-codegen-component/docs/architecture.md:475-479).
