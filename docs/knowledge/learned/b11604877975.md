- Secrets are delivered as mounted files when `CREDENTIAL_KIND` is `"mounted-file"` (datrix/docs/architecture/architecture-overview.md:554).  
- The runtime reads the secret via the baked `CREDENTIAL_FILE_PATH` constant with no environment lookup (datrix/docs/architecture/architecture-overview.md:569).  
- For LOCAL provider, secrets are accessed from the mounted secrets directory path (datrix/docs/architecture/architecture-overview.md:561).  
- Compose delivers secrets by mounting exactly the files listed in the application secret placement (datrix/docs/architecture/architecture/pipeline-and-capabilities.md:182).  
- Provider credentials reach containers as mounted files whose handle is listed in the secret placement (datrix-codegen-docker/docs/architecture.md:776-777).  
- The runtime-requirements manifest states who supplies the secret via `provisioning_authority` (datrix-codegen-docker/docs/architecture.md:777).
