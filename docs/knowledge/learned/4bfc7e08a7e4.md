The semantic baseline manifest is validated by `tests/unit/test_semantic_baseline.py` against `tests/fixtures/semantic_baseline/manifest.json` datrix-semantic/docs/architecture.md:142-144. When the resolved Application model gains a field intentionally, the test will fail and the manifest must be regenerated manually to reflect the new structure. The process is not automated and requires developer intervention to update the committed fixture corpus. datrix-semantic/docs/architecture.md:142-144
