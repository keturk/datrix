A BLOCKED claim is valid only if it contains all four required elements:
1. **ERROR TEXT**: Verbatim, unabridged error text (datrix/claude-config/.claude/skills/_shared/execution-contract.md:79).
2. **ATTEMPTED**: The actual fix tried, specified as `file:line` with changes, proving code was written and run (datrix/claude-config/.claude/skills/_shared/execution-contract.md:80-81).
3. **WHY IT FAILED**: The specific mechanism that defeated the attempt (datrix/claude-config/.claude/skills/_shared/execution-contract.md:82).
4. **BLOCKER CODE**: One of B1–B4 codes with a sentence explaining its application (datrix/claude-config/.claude/skills/_shared/execution-contract.md:83).
