# Environment Variables

## Quick Start

1. Copy `.env.example` to `.env`
2. Update values for your environment
3. Start services: `docker compose up -d`

## Variables

### Standard Configuration

#### `SPRING_PROFILES_ACTIVE`
- **Required:** Optional
- **Default:** `default`
- **Description:** Active Spring profile (development, staging, production)

### Database Configuration

#### `DATABASE_URL`
- **Required:** Required
- **Default:** `jdbc:postgresql://db:5432/db_db`
- **Description:** JDBC database connection URL

#### `POSTGRES_DB`
- **Required:** Required
- **Default:** `db_db`
- **Description:** PostgreSQL database name

#### `POSTGRES_USER`
- **Required:** Required
- **Default:** `db`
- **Description:** PostgreSQL username

#### `POSTGRES_PASSWORD`
- **Required:** Required
- **Default:** `changeme`
- **Description:** PostgreSQL password

### Service Configuration

#### `WAREHOUSE_SERVICE_HOST`
- **Required:** Optional
- **Default:** `localhost`
- **Description:** WarehouseService host address

#### `WAREHOUSE_SERVICE_PORT`
- **Required:** Optional
- **Default:** `8000`
- **Description:** WarehouseService port

### OpenTelemetry (OTLP)

#### `OTEL_EXPORTER_OTLP_ENDPOINT`
- **Required:** Optional when tracing is enabled in system observability
- **Default:** From system tracing configuration, or set by Docker Compose for platform-managed Jaeger
- **Description:** When set, overrides the configured OTLP URL before the exporter is created.
