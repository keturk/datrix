# Environment Variables

## Quick Start

1. Copy `.env.example` to `.env`
2. Update values for your environment
3. Start services: `docker compose up -d`

## Variables

### Standard Configuration

#### `DEBUG`
- **Required:** Optional
- **Default:** `false`
- **Description:** Enable debug mode

#### `ENVIRONMENT`
- **Required:** Optional
- **Default:** `development`
- **Description:** Environment name (development, staging, production)

#### `LOG_LEVEL`
- **Required:** Optional
- **Default:** `info`
- **Description:** Logging level (debug, info, warning, error)

### Database Configuration

#### `DATABASE_URL`
- **Required:** Required
- **Default:** `postgresql+asyncpg://db:changeme@localhost:5432/db_db`
- **Description:** Database connection URL

#### `POSTGRES_DB`
- **Required:** Required
- **Default:** `db_db`
- **Description:** PostgreSQL database name

#### `POSTGRES_USER`
- **Required:** Required
- **Default:** `db`
- **Description:** PostgreSQL username

#### `POSTGRES_PASSWORD`
- **Required:** Required
- **Default:** `changeme`
- **Description:** PostgreSQL password

### Service Configuration

#### `BOOK_SERVICE_HOST`
- **Required:** Optional
- **Default:** `localhost`
- **Description:** BookService host address

#### `BOOK_SERVICE_PORT`
- **Required:** Optional
- **Default:** `8000`
- **Description:** BookService port

### OpenTelemetry (OTLP)

#### `OTEL_EXPORTER_OTLP_ENDPOINT`
- **Required:** Optional when tracing is enabled in system observability
- **Default:** From system tracing configuration, or set by Docker Compose for platform-managed Jaeger
- **Description:** When set, overrides the configured OTLP URL before the exporter is created. If exporter setup fails (invalid URL, unreachable collector), the service logs ``tracing_setup_failed`` and continues without exporting traces.
