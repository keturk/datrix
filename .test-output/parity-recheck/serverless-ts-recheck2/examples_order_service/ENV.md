# Environment Variables

## Quick Start

1. Copy `.env.example` to `.env`
2. Update values for your environment
3. Start services: `docker compose up -d`

## Variables

### Standard Configuration

#### `PORT`
- **Required:** Optional
- **Default:** `3000`
- **Description:** HTTP port for the NestJS application

#### `NODE_ENV`
- **Required:** Optional
- **Default:** `development`
- **Description:** Environment name (development, staging, production)

### Database Configuration

#### `DATABASE_URL`
- **Required:** Required
- **Default:** `postgresql://localhost:5432/app`
- **Description:** Database connection URL

#### `POSTGRES_DB`
- **Required:** Required
- **Default:** `app`
- **Description:** PostgreSQL database name

#### `POSTGRES_USER`
- **Required:** Required
- **Default:** `postgres`
- **Description:** PostgreSQL username

#### `POSTGRES_PASSWORD`
- **Required:** Required
- **Default:** `changeme`
- **Description:** PostgreSQL password

### Secrets Configuration

#### `SECRETS_BACKEND`
- **Required:** Optional
- **Default:** `environment`
- **Description:** Secrets provider backend (environment, vault, aws)

#### `JWT_SECRET`
- **Required:** Required
- **Default:** (none)
- **Description:** JWT signing secret key

### Service Configuration

#### `INGESTION_SERVICE_HOST`
- **Required:** Optional
- **Default:** `localhost`
- **Description:** IngestionService host address

#### `INGESTION_SERVICE_PORT`
- **Required:** Optional
- **Default:** `8002`
- **Description:** IngestionService port

#### `ORDER_SERVICE_HOST`
- **Required:** Optional
- **Default:** `localhost`
- **Description:** OrderService host address

#### `ORDER_SERVICE_PORT`
- **Required:** Optional
- **Default:** `8001`
- **Description:** OrderService port

### OpenTelemetry (OTLP)

#### `OTEL_EXPORTER_OTLP_ENDPOINT`
- **Required:** Optional when tracing is enabled in system observability
- **Default:** From system tracing configuration, or set by Docker Compose for platform-managed Jaeger
- **Description:** When set, overrides the configured OTLP URL before the exporter is created. If exporter setup fails (invalid URL, unreachable collector), the service logs ``tracing_setup_failed`` and continues without exporting traces.
