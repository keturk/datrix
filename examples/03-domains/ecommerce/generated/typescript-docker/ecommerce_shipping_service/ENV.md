# Environment Variables

## Quick Start

1. Copy `.env.example` to `.env`
2. Update values for your environment
3. Start services: `docker compose up -d`

## Variables

- **Description:** HTTP port for the NestJS application

- **Required:** Optional

### Secrets Configuration

#### `SECRETS_BACKEND`
- **Required:** Optional
- **Default:** `environment`
- **Description:** Secrets provider backend (environment, vault, aws)

#### `JWT_PUBLIC_KEY_FILE`
- **Required:** Required when the system declares gateway JWT auth
- **Default:** (none)
- **Description:** Path to the PEM file holding the asymmetric JWT **public** key. Read at verification time, never cached into configuration. Provisioned and mounted by the deployment.

#### `JWT_PRIVATE_KEY_FILE`
- **Required:** Required when the system declares gateway JWT auth
- **Default:** (none)
- **Description:** Path to the PEM file holding the asymmetric JWT **private** key. Read only by a signer, at signing time. Provisioned and mounted by the deployment; the value never appears in generated source, configuration, or logs.

#### `JWT_ALGORITHM`
- **Required:** Optional
- **Default:** the algorithm resolved from the system gateway config
- **Description:** Asymmetric signing algorithm pinned during verification (RS/PS/ES family). A symmetric algorithm is rejected at generation time.

#### `JWT_ISSUER`
- **Required:** Optional
- **Default:** the issuer resolved from the system gateway config
- **Description:** Expected `iss` claim.

#### `JWT_EXPIRY`
- **Required:** Optional
- **Default:** `3600`
- **Description:** Token lifetime in seconds.

### OpenTelemetry (OTLP)

#### `OTEL_EXPORTER_OTLP_ENDPOINT`
- **Required:** Optional when tracing is enabled in system observability
- **Default:** From system tracing configuration, or set by Docker Compose for platform-managed Jaeger
- **Description:** When set, overrides the configured OTLP URL before the exporter is created. If exporter setup fails (invalid URL, unreachable collector), the service logs ``tracing_setup_failed`` and continues without exporting traces.
